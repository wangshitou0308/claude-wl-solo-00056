# 离线寻星路径预演台

面向手动望远镜观测者的**星跳（star-hopping）路径预演工具**。针对两大现场痛点：

- **寻星镜倒像/镜像让人迷失方向** —— 星图上叠加经光学变换（正像 / 水平镜像 / 倒像）后的移动箭头，每跳再配一张目镜视场小图，直接告诉你"在目镜里该往哪边移"。
- **星点随时间落低** —— 每次到达都按 `初值 + 0.250684 × 累计分钟`（mod 360°）推进恒星时，重新计算高度，过低即排除，并在结果中逐跳列出高度余量。

全部计算在浏览器本地完成，无需联网。构建产物是**单个自包含 HTML 文件**，双击即可离线打开。

## 快速开始

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（Vite 热更新）
npm test           # 运行单元测试（vitest，36 个用例）
npm run build      # 类型检查 + 构建单文件 dist/index.html
npm run preview    # 预览构建产物
```

## 输入格式（JSON）

```jsonc
{
  "stars": [                          // 2～120 颗，编号唯一
    { "id": 1, "raDeg": 80.0, "decDeg": 20.0, "mag": 1.5 }
  ],
  "startId": 1,                       // 起点编号（须存在于 stars）
  "targetId": 7,                      // 目标编号（须存在且 ≠ startId）
  "latitudeDeg": 39.9,                // 观测纬度 [-90, 90]
  "initialSiderealDeg": 125.0,        // 初始恒星时（度）[0, 360)
  "fovDeg": 5.0,                      // 视场角（度）(0, 180]
  "limitingMag": 6.5,                 // 极限星等
  "minutesPerHop": 4,                 // 每跳分钟数（> 0）
  "minAltitudeDeg": 15.0,             // 最低高度（度）[-90, 90]
  "opticsMode": "inverted"            // erect 正像 / mirror 水平镜像 / inverted 倒像
}
```

任何字段非法（坐标越界、编号重复、引用不存在的星、数量不在 2～120 等）都会**整次拒绝**，并逐条列出错误位置与原因，绝不用部分数据继续计算。

## 计算规则

| 规则 | 公式 / 说明 |
| --- | --- |
| 第 k 次到达恒星时 | `lst(k) = (initialSiderealDeg + 0.250684 × k × minutesPerHop) mod 360` |
| 候选星 | 星等 ≤ 极限星等 |
| 进入视场 | 相邻两跳球面角距 ≤ 视场角（球面 Vincenty 公式，数值稳定） |
| 到达高度 | `sin(alt) = sinδ·sinφ + cosδ·cosφ·cosH`，`H = lst − ra`，须 ≥ 最低高度 |
| 路径约束 | 不重复星点，最多 8 跳 |
| 优选顺序 | ① 跳数最少 → ② 全程最低高度余量最大 → ③ 总角距最短 → ④ 编号序列字典序最小 |

搜索实现：按跳数迭代加深，在固定跳数内用分支限界（余量上界 / 角距下界启发 / 字典序剪枝）枚举全部简单路径，保证结果精确最优，而非近似。

## 页面功能

- **星图**：等距圆柱投影（北在上、东在左），显示全部恒星（灰 = 星等超限）、各跳出发星的视场圈、真实路径虚线，以及**经光学变换后的彩色移动箭头**（数字为跳序）。
- **逐跳卡片**：到达恒星时（度 + h:m:s）、高度与余量、方位角、本跳角距，以及目镜视场小图（变换后的目标方向箭头）。
- **修改输入立即废止旧结果**：任何编辑都会清空旧结果并提示重新预演。
- **无路报告**：按搜索层（第 1～8 跳）列出因视场或高度被排除的边界星（含角距、超出量、到达高度、余量），不返回半条路线。
- **证据下载**：一键下载 JSON，含输入摘要、常量与公式、完整路径（每跳的恒星时/时角/高度/方位/角距/余量）或分层边界星报告。

## 设计说明

- **恒星时用度制**：与输入的度制赤经直接相减得时角，避免单位混淆；`0.250684°/min` 为恒星时相对平太阳时的推进速率。
- **余量包含起点**：起点在初始恒星时的高度也须 ≥ 最低高度，且计入"全程最低高度余量"，保证整趟观测从第一步起就满足约束。
- **边界星口径**：每层对每颗前沿星，列出"视场内但高度不足"的全部候选星，以及"超出视场"的最近 3 颗候选星（提示再远一点就能够到谁）；同层同星同原因去重，每层上限 500 条防病态输入。
